            What makes a suggestion land

            • Say what you are trying to do. There may already be a way, or a better one than the feature you pictured.
            • One idea per message. Send as many messages as you like.
            • A screenshot of another addon doing it is worth a paragraph.

            • What you did, what you saw, what you expected.
            • The error text, if there was one. It names the exact line that failed.

            Help

            Before you report

            1. Update. A lot gets fixed between versions. The newest ones are on the Addons page.
            2. Type /reload. If the problem is gone after that, say so in the report. It still helps.
            3. Try it again on purpose. If you can make it happen twice, write down what you did.

            Copying an error from the game

            The game hides Lua errors unless you ask for them. Type this in chat once, then make the problem happen again:

            /console scriptErrors 1

            An error window comes up when something fails. Select all of its text, copy it, and paste it into the report. To switch the windows off again, type the same line with a 0.

            If you use BugSack and BugGrabber, open BugSack from its minimap button and copy the error from there instead.

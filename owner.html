For Zac. Wire the report form to Discord, test it, and see how the rest of the site is kept up. Nothing you type here is saved or sent anywhere except to Discord when you press the test button.

1. Make a webhook in Discord

  1. Pick the channel reports should land in. A private channel only you can see is best. A forum channel is even better: every report becomes its own post you can answer, tag and close.
  2. Server Settings, then Integrations, then Webhooks, then New Webhook.
  3. Give it a name, pick the channel, press Copy Webhook URL.

2. Paste it here and test it

3. Put it in config.js

Open config.js in the site's folder (in GitHub Desktop, Ctrl+Shift+F opens the folder). Find each of these three lines in it and make it read as below. Only the first is needed: paste the address between its two quotes. Save, then commit and push in GitHub Desktop. The site picks it up about a minute later.


    

  


  

    
If someone posts junk through it

    
The address sits in a file anyone can read, so someone who goes looking could post into that channel. It cannot read anything, ping anyone or touch the rest of your server. If it happens: delete the webhook in Discord, make a new one, and paste the new address into config.js. Two minutes.

    
If it keeps happening, extras/relay-worker.js hides the address behind a small free relay. Its first lines say how to set it up.

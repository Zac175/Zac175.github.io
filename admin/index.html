Set up the admin panel

You sign in with a password and a six-digit code from an authenticator app on your phone (Google Authenticator, Microsoft Authenticator, Authy, 1Password...). To prove it is you, a code goes to your Discord reports channel first.

The Discord webhook is not set on the server yet, so there is nowhere to send the code. Do step 2 of "Setting it up" in the README first.

  1. Get a code in Discord

  2. Add it to your authenticator app

    In the app, add an account and pick Enter a setup key (sometimes "Enter code manually"). Name it zacaddons.com and type this key:

    On the phone itself? Open it in the app. Time-based, 6 digits, 30 seconds: the usual settings.

  3. Pick a password

    At least 12 characters. A few random words is fine. Your password manager can make one.
